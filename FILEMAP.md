# File map

- `ProjectSettings/ProjectVersion.txt` — pinned Unity LTS editor baseline.
- `ProjectSettings/ProjectSettings.asset` — PC settings and active Input System.
- `Packages/manifest.json` — package and Unity module baseline.
- `Assets/Scenes/OfflineDriving.unity` — playable offline race scene.
- `Assets/Prefabs/` — generated car, track, and bot prefabs.
- `Assets/Scripts/Gameplay/` — driving, camera, bots, race, recovery, and damage.
- `Assets/Tests/` — EditMode and PlayMode coverage for the offline loop.
- `Assets/README.md` — reserved asset folder for later checkpoints.
- `README.md` — setup prerequisites and validation boundary.
